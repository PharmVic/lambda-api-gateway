 Lambda + API Gateway Integration

This project demonstrates how to connect an AWS Lambda function with API Gateway
to build a simple serverless API endpoint. The Lambda function processes POST requests
and returns a JSON response.

 Features
- Lambda function written in Python
- Integrated with API Gateway
- Supports JSON input and output
- Logs requests to CloudWatch

 How to Deploy
1. Create a new Lambda function in AWS.
2. Add your code from `lambda_function.py`.
3. Create an API Gateway REST API and connect it to your Lambda.
4. Deploy and test using Postman.
